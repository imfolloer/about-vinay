INVEST (High Value / High Tech Quality)

Strategic long-term core platforms. Allocation of R&D capital for expansion.

TOLERATE (High Value / Low Tech Quality)

Keep short-term to avoid business disruption; schedule technical debt refactoring.

MIGRATE (Low Value / High Tech Quality)

Merge functionality into primary systems or re-allocate underlying infrastructure.

ELIMINATE (Low Value / Low Tech Quality)

Decommission immediately to reduce license overhead, hosting, and security attack surface.

METRIC 2

Lead Time for Changes

Time required for committed code to reach live production users.

METRIC 3

Change Failure Rate

Percentage of production deployments that result in degradation or outages.

METRIC 4

Mean Time to Restore (MTTR)

Average duration required to recover from a production outage.

Atomicity

All operations in a transaction execute successfully, or the entire transaction rolls back completely ("all or nothing").

Consistency

Data transitions from one valid state to another, enforcing all integrity constraints and foreign key rules.

Isolation

Concurrent transactions execute independently without interfering with one another's intermediate state.

Durability

Once a transaction commits, data updates persist permanently even in the event of system power loss or failure.

SAF Framework Case Interview Simulator

Structure your responses using **Situation, Assessment, Findings, Recommendation, and Business Impact**.

Scenario: GPL License Contamination in Core SaaS Engine

Critical IP Red Flag
S — Situation (Context & Thesis)

Target is a $20M ARR SaaS platform providing logistics routing software being acquired by a Private Equity sponsor for a bolt-on expansion.

A — Assessment (Methodology & Tools)

Performed automated Black Duck open-source code composition analysis (SCA) across the core routing engine repository and audited developer git logs.

F — Findings (Discovered Risks)

Identified GPL v3.0 copyleft library directly linked inside proprietary algorithm code, creating catastrophic risk of IP contamination requiring source code disclosure.

R — Recommendation (100-Day Plan Action)

Mandate seller re-write of infected algorithm prior to close, escrow $1.5M of purchase price, and isolate code module into an independent service API during 100-Day Plan.

B — Business Impact (EBITDA & Valuation)

Protects proprietary moat, defends target's 12x EBITDA valuation multiple, and eliminates post-acquisition litigation liability.
